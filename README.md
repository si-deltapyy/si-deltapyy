### 🏢 About PT Delta Teknologi Indonesia

Saya pendiri **PT Delta Teknologi Indonesia** (DeltapyTech), penyedia solusi IT terintegrasi yang berfokus pada:

* 🌐 **Web Development**: Mengerjakan sistem web skala produksi, *landing page*, dan *custom enterprise web apps*.
* ☁️ **Hosting & Infrastructure**: Pengelolaan server, *reverse proxy*, hingga optimasi kontainer (LXC/Docker).
* 🚀 **SEO & Performance**: Optimasi kecepatan performa web dan visibilitas di mesin pencari.
